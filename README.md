# PhaseOut Chrome Extension
Uses in-browser face recognition to remove a certain face from the internet.

## Installation
The extension is work-in-progress and before it is committed to Chrome Web Store it requires a manual installation:
* Download the code as .zip file and unpack it;
* In Chrome, go to Extensions, enable Developer mode, which is a slider that is located in the upper right;
* Click Load Unpacked button on the top left and point to the unpacked directory;
* Upload pictures of the faces that you would like to phase out of the internet, close the option dialog;
* **Important:** enable Allow user scripts slider;
* Navigate to a desired tab, and switch on the extension by clicking its logo in the extension bar.
